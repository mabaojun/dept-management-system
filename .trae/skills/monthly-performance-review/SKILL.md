# 月度绩效参考意见生成

## 描述

调用部门管理系统的 AI 分析能力，汇总成员当月工作日志（AI 已解析出工作量、产出、风险点）与任务完成数据，生成结构化月度绩效参考意见，供部门管理者考核时参考。

## 使用场景

- 用户说「生成本月绩效参考意见」「评估一下邱金宝这个月的表现」「出月度考核材料」时
- 月底/月初例行绩效整理时

## 指令

1. 确认月份（YYYY-MM）与对象：全体成员或指定成员。
2. 检查前提数据是否齐全：
   - `GET /worklogs?month=YYYY-MM` 查看日志数量；若成员日志很少，先提醒用户「该成员本月日志仅 N 条，分析结论可能失真，建议先催交日志」。
   - `GET /dashboard/summary` 查看任务完成率与负载分布。
3. 调用 `POST /analysis/monthly-review`，body `{ "month": "YYYY-MM", "user_id": <可选> }`。系统会综合任务完成数量/质量、日志解析结果生成参考意见；未配置 LLM API Key 时返回 Mock 演示数据，需向用户说明并提示在「系统设置」页配置真实 API Key。
4. 结果解读与输出，按以下结构汇报：
   - 总览：成员数、日志条数、任务完成率
   - 逐人：完成任务数 / 进行中 / 阻塞、日志亮点、AI 参考意见摘要
   - 重点提醒：urgent 任务（如朱总催办的锦水河西支支出）与 blocked 任务（法院展厅、孔村）的影响
5. 明确声明：本意见为 AI 参考结论，最终考核由管理者裁定；后续接入知识库后将补充「未知流程工作量」（如签约流程所需步骤、文件、紧迫性）的补全提醒与自动评分。
6. 历史意见可 `GET /analysis/reviews?user_id=` 查询，用于月度对比。

## 示例

输入：「帮我看下 9 月份大家绩效怎么样」
做法：`GET /dashboard/summary` + `POST /analysis/monthly-review {month: "2026-09"}` → 输出总览与逐人摘要，末尾附紧急/阻塞任务提醒。
