# 周一晨会数据准备

## 描述

晨会前从部门管理系统拉取任务与看板数据，按「紧急 → 阻塞 → 本周重点 → 待补充事项」生成晨会要点清单，并提示跟踪表需要更新的地方。

## 使用场景

- 用户要求「准备今天晨会」「给我本周重点」「汇总当前阻塞任务」时
- 每周一例行数据同步时

## 指令

1. `GET /tasks` 拉取全部任务（可按 status 过滤）。
2. 按以下顺序整理晨会要点：
   - 🔴 紧急（priority=urgent）：逐项列出负责人与催办来源，置顶
   - 🚧 阻塞（status=blocked）：列出阻塞原因与解锁条件，标注影响（如「孔村项目影响本月计收」）
   - 🔄 本周推进重点（priority=high）：按负责人分组
   - ⏳ 待启动与待补充：列出缺少时间节点/细节的任务（description 中含「待补充」），晨会上让负责人确认
3. 按负责人生成个人任务清单（陈卓 / 邱金宝 / 马保俊 / 杨美园晓 / 毕泗欣），已完成（done）任务不列。
4. 输出为紧凑的 Markdown 清单，方便直接粘贴到晨会文档。
5. 若用户提供了新版跟踪表 md，提醒先走「import-tracking-table」技能同步系统，再生成晨会要点。
6. 结尾固定提醒事项：
   - 每周一晨会前同步更新一次跟踪表
   - 有新待办（如签约类流程：沟通 → 额度 → 签约 → 开票 → 付款）可在系统中补充任务节点，避免工作量遗漏

## 示例

输入：「周一了，准备下晨会」
做法：拉取任务 → 输出「🔴 紧急：锦水河西支支出（陈卓，朱总催办）；🚧 阻塞：法院展厅（院长外出）、孔村（等合同）；本周重点：DCMM 挂票（邱金宝）、历史回款（杨美园晓）…」
